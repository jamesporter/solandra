# Getting Started

## Install

Install [Solandra from npm](https://www.npmjs.com/package/solandra):

```sh
npm install solandra
```

You can also use `pnpm add solandra` or `yarn add solandra`. Start with [Canvas Basics](/docs/canvas-basics) to create your first sketch.

To run this website and its examples locally, clone the [repository](https://github.com/jamesporter/solandra), run `pnpm install`, then `pnpm dev`.

For a browser-based example, try the [React CodeSandbox](https://codesandbox.io/p/sandbox/solandra-0-18-react-example-ll5gjg) (uses Solandra v0.18).
